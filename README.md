# Alabanza El Carmen

Canciones con acordes, cambio de tono y creación de alabanzas (PowerPoint y cancionero) desde el navegador.

Ábrelo aquí: https://juanalvarezo.github.io/alabanza-el-carmen/

Se puede instalar en la pantalla de inicio del móvil y funciona sin conexión después de la primera visita. Lo que guarda cada persona (alabanzas, tonos) se queda en su navegador.

Estos archivos se generan con `herramientas/web.py` del cancionero; no se editan a mano.
